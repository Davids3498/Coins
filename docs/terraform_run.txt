  PARITY RESULT
  ---------------------------------------------------------------------------
                         local (registry)      local (baked)        Fargate
  model_version          10                    10                   10
  model_source           registry              local                local
  top-1 label            NERO                  NERO                 NERO
  top-1 probability      0.8328765630722046    0.8328765630722046   0.8328765034675598
  top-3 ordering         NERO, GORDIAN I, DIDIUS JULIANUS  (identical on all three)

  Same champion, same label, same ranking. The two LOCAL paths are bit-identical,
  which is the result that matters for the bake: freezing the model into the image
  introduces exactly zero numerical drift.

  Local vs Fargate agrees to 7 significant figures (relative delta 7.2e-08), not
  bit-for-bit. That gap is CPU microarchitecture, not the deployment: float32 conv
  and GEMM kernels reassociate differently across SIMD widths, so this developer
  machine and the Fargate host reduce the same sums in a different order. It is
  isolated to hardware precisely BECAUSE the two local paths matched bit-for-bit
  on one machine. Bit-identical float across CPUs would need deterministic kernels
  and a pinned thread count, which costs throughput and proves nothing extra here.
